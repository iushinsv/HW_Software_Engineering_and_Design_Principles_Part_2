# Домашнее задание #1.
Сделать два сервиса:
Сервис 1 - сервер.
Currency rate provider
Возвращает текущий курс валют (USDRUB). В
качестве курса валюты можно взять любое число
+/- какой-то рандом на каждый запрос, чтобы
число не было константой. Сервис должен иметь
синхронное API, основанное на RPC (любая
технология, на выбор).
Сервис 2.
Rate printer
В цикле раз в 5 секунд делает запрос на
currency-rate-provide
Выводит на экран курс валют
Оба сервиса на Java.
Как именно будет выглядеть API - на ваш выбор.
Для создания проекта лучше использовать spring-initialzr
